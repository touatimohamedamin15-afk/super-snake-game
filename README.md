# 🐍 Super Snake Game (لعبة الثعبان الخارقة)

A modern, highly-polished, feature-rich web-based Snake game built with HTML5 Canvas, Vanilla JavaScript, and Web Audio API. Featuring a neon cyberpunk aesthetic, strict wall-collision mechanics, particle effects, golden apples, advanced scoring, and responsive touch controls.

---

## ✨ Features / الميزات الرئيسية

- **🎨 Neon Cyberpunk Design:** Gorgeous dark-mode styling with glowing elements, subtle grid patterns, and dynamic UI panels.
- **🍎 Multiple Apple Types:** Regular red apples for standard points and rare **Golden Apples** for bonus points and high multipliers.
- **⚡ Advanced Scoring & Progression:** Dynamic score multiplier, level-up scaling, and speed increase every 5 apples eaten. High score persistence via `localStorage`.
- **💥 Visual & Audio Effects:** Particle explosion animations on food consumption and synthetic retro sound effects powered by the **Web Audio API** (no external audio files needed).
- **💀 Strict Wall & Self Collision:** Classic arcade rules — hitting any wall or your own tail results in an immediate Game Over with death cause details.
- **📱 Universal Controls:** Fully playable with Keyboard arrow keys / WASD, on-screen mobile D-Pad buttons, and smooth touch swipe gestures.

---

## 🎮 How to Play / طريقة اللعب

1. Open `index.html` in any modern web browser.
2. Click **"ابدأ اللعبة" (Start Game)**.
3. Use **Arrow Keys / WASD** (or mobile touch controls) to guide the snake.
4. Eat apples to grow and increase your score, but avoid crashing into walls or your own body!

---

## 🛠️ Tech Stack / التقنيات المستخدمة

- **HTML5 Canvas** (High-performance rendering)
- **Vanilla JavaScript (ES6+)** (Game logic, particle system, and state management)
- **Web Audio API** (Procedural sound effects)
- **CSS3 / Flexbox / Grid** (Responsive futuristic UI styling)
